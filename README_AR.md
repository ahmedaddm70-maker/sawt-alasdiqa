# صوت الأصدقاء — نسخة البداية

هذا مشروع Android أولي بلغة Kotlin وJetpack Compose.

## ماذا يحتوي؟
- واجهة عربية داكنة.
- قائمة تجريبية لأشخاص.
- بحث محلي بالاسم أو الدولة أو اللغة.
- أزرار تنقل سفلية.
- زر المكالمة ظاهر للتصميم فقط؛ لم يتم ربطه بمكالمة حقيقية بعد.

## بناء APK من GitHub Actions
1. ارفع كل ملفات هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. اختر Build Android APK ثم Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم sawt-alasdiqa-debug-apk.
5. فك ضغط الملف وثبّت app-debug.apk على هاتفك.

## معرف التطبيق
com.sawt.alasdiqa

## الخطوات القادمة
1. Firebase Authentication لتسجيل الحسابات.
2. Cloud Firestore للملفات الشخصية والرسائل والحضور.
3. Agora أو WebRTC للمكالمات الصوتية.
4. قواعد أمان، حظر وإبلاغ، وإشعارات.
5. إعداد توقيع إصدار Release قبل النشر.

لا تضع مفاتيح سرية أو رموز Agora داخل مستودع عام.
